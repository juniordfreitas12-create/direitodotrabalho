# Direito em Foco

Blog em Jekyll para GitHub Pages.

## Como publicar um post novo

1. Crie um arquivo em `_posts/` com o nome `AAAA-MM-DD-titulo-do-post.md`.
2. Comece com este cabeçalho:

```
---
layout: post
title: "Título do post"
date: AAAA-MM-DD
category: Direitos
excerpt: "Resumo de uma ou duas frases que aparece na página inicial."
---
```

3. Escreva o texto em Markdown e dê o commit.

Posts com data futura só aparecem depois dessa data.
